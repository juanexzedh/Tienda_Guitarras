# Guitar Store

Final project developed using HTML, CSS, JavaScript and Laravel.

## Features

* Product catalog
* Product detail page
* Shopping cart
* Checkout process
* Login system
* Administrator panel
* CRUD operations for guitars
* Protected API routes
* Authentication system

## Technologies

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Laravel
* MySQL
* REST API

## Installation

### Frontend

Open:

index.html

### Backend

1. Install dependencies

composer install

2. Configure environment variables

Create `.env`

3. Generate application key

php artisan key:generate

4. Run migrations

php artisan migrate

5. Start server

php artisan serve
